# 路径兼容与语义映射

## 辅助文件及旧材料

| 原位置/语义 | 新位置/处理 | 理由 |
| --- | --- | --- |
| `README.md` 的规则库介绍 | `README.md` 与 `docs/quickstart.md` | 增加可实际使用的协作入口，不把指南变成第二套强制规则 |
| `STATE.md` 的私人发布/模型历史 | 以本候选状态重写 `STATE.md` | 不迁旧接受/迁移结论；目标项目状态不入公共库 |
| `evidence/` 历史审核/发布材料 | 不复制 | 旧证据不为新泛化正文背书；必要私有依据留原授权范围 |
| `references/` 中的旧参考入口 | 不复制、不作为新运行依赖 | 本包统一编写正文，不把未采用参考指南当定稿 |
| 项目身份、实际任务/作者、目录、版本与暂停状态 | 继续留原项目规则/现有记录 | 新库只含必要模板，不转移私密内容或取消停点 |
| 私人模型固定选择与服务设置 | 部署者配置或原项目明确覆盖 | 不能变成新用户默认，采用本库不自动修改已有设置 |
| 私人备份、顾问调用、分享或外发授权 | 删除公共继承，仅在相应项目核原授权 | 方法可复用，个人许可不可转授 |
| 真实聊天、记忆、原始日志、存档、截图、凭证 | 排除，未导入 | 不为解释方法扩大资料读取或公开面 |

## 一致保留的含义

用户提目标和反馈；受授权网页版分析并写任务包/规则；Dot 核查和原文转交；主控守方向、依赖、风险和技术采用；主要实现者端到端交付；必要独审独立。没有强制多代理或本地设计主控。

先机制后内容、合理独立并行、单一写域、直接交接、验收前置、真实证据和数据恢复保持。无新信息退避，不为 active 空转，结束协调回合不取消任务；通知不可靠采用已有授权下的有界检查。真实反例与必要诊断不因精简被跳过。

没有改变暂停/拒绝、旧失败、冻结输入和接受门槛。新库发布、入口迁移、任务加载、模型配置及恢复任务分开证明。公共路径未重排，因此无失效兼容别名需要创建。
