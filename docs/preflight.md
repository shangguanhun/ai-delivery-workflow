# 部署前核查清单

用于本候选的审阅、私有建仓及后续安全采用。复用原记录，适用项核实一次；不是新增日报或多级审批。当前未执行的项目保持未完成，不预勾为通过。

## 候选与资料范围

- [ ] 核候选版本、所有文件与外部 SHA256 清单一致；未混入其他附件、构建脚本临时文件或 `.git`。
- [ ] 正文、文件名、链接和元数据不含个人账号/真实任务标识、绝对路径、用户个案、私人许可、真实进度和凭证。
- [ ] 未读取或复制本地记忆、未授权项目规则、其他私密会话；公开包不含来源私有身份。
- [ ] 项目专属规则和模型例外继续在项目；一般规则不伪造常设 push、建仓、费用或外发权限。
- [ ] 通知、工具、模型、计费和记忆能力均按实际支持核实，没有免费、无限或自动接管保证。

## 独审与授权采用

- [ ] 合格独审覆盖确切候选及语义映射，审查者不是作者或采用者；作者自检未冒称独审。
- [ ] 建仓、push、入口修改、通知等实际动作分别有仍有效授权，用户暂停与平台拒绝保持。
- [ ] 新建空私有仓库，只选净化文件，不 fork/镜像或复制旧历史；远端/可见性回读准确。
- [ ] live 基线与并行修改已核；回退只覆盖本次规则/指针，不动真实项目数据。

## 目标环境

- [ ] 用户允许的安全节点才迁移；运行中回合不打断，暂停项目不为加载唤醒。
- [ ] 目标环境实际可读所需全文；旧路径可定位，新固定提交或清单明确，项目覆盖未被抹去。
- [ ] 发布、入口切换、任务加载和模型回执分别有证据；未知保留，不把 Git 成功当全任务生效。
- [ ] 消息若会激活任务，发送前核恢复授权；否则只保留通知稿。
- [ ] 所需 GUI/进度与写域单一负责，接收路径可用；无新信息退避，不建额外监控。

## 面向用户的交付

- [ ] 实际可用入口、候选身份、进度来源、操作、退出与未验范围清楚；不是只交源码或截图。
- [ ] 必要独审、保存/恢复、真实运行和产品接受边界不因新库而减少。
- [ ] 小任务不被强制扩成多代理，大任务按真实耦合选择能力；独立工作仅在有净收益时并行。

## 将来公开前另核

- [ ] 已明确公开授权、对外许可与内容权利；当前“可能公开”未被当成立即许可。
- [ ] 新库自创建以来的完整历史、讨论/附件/发布资产和填写过的模板已在授权范围内复查，无敏感残留。
- [ ] 没有把私人部署记录、接收账号或实际项目状态公开；可见性变更后实际回读，不提前宣称公开完成。

尚未满足公开项不妨碍继续有授权的私有候选审查，但不得因此省略公开前的核查。完整流程见 [迁移指南](migration.md)。
