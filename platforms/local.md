# 本地环境适配

规则版本：`portable-collaboration-v1`。与 [公共入口](../AGENTS.md) 和适用阶段共同使用。

核实际连接电脑、工程目录、规则根、任务身份、服务、入口和进度。旧端口、另一环境的路径或网页聊天中的描述都不证明本机现状。通过网页客户端控制本机仍属本地执行。

保留原工作树、项目规则、未提交改动、存档和所有权。同一 GUI/存档会话仅一位操作者；并行作者不得共享可变运行状态。采用规则不能强制重启有效工作、热改冻结候选或改变全局配置。

是否支持任务派发、独立上下文、模型切换、电脑操作、截图录音和完成通知，必须通过当前已授权工具核实。不可用就保留该分支未运行，不用更换工具绕过拒绝；不假定套餐或后台额度无限。

对已获准启动的长任务，优先在同一工程会话用客户端支持的持续目标（例如 Codex 的 `/goal`）记录结果、约束、验收和现有计划入口，不复制整份计划。已有目标原地接续，确需变更再在授权范围内编辑，不为重排任务清除或重建目标。核实际目标正文、状态和首个执行回执；目标活跃不是任务已运行或验收通过，不因切换模式、模型或共享额度改变权限。没有该能力就沿原任务记录与现有进度机制执行。

本地提交、远端上传、目标入口采用、任务加载与模型回执分别记录。已暂停任务只在明确恢复后接续；规则通知本身不是唤醒命令。

跨环境时读 [文件交接](../workflows/v1.9/file-account-handoff.md)。本地路径、登录、浏览器进度与服务不会随项目分享自动迁移；必要文件分别核可读、可运行，保留原件。授权范围外的缺口不通过导出整机或复制记忆来弥补。
