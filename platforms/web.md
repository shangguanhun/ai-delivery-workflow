# 网页工作区适配

规则版本：`portable-collaboration-v1`。与 [公共入口](../AGENTS.md) 和适用阶段共同使用。

先核当前是普通分析聊天、可执行工作区还是连接本机的客户端。连接本机执行时用本地适配，不混用默认。只有实际取得材料、工具可用且授权覆盖，才可执行相应动作。

通过获准连接器读取固定提交的具体文件，标明完整/局部读取与缺口。链接不等于内容，远端快照不等于当前本地采用。没有代码或运行工具时只交分析/任务包，不编造运行、截图或本地改动。

网页版产品与规则作者保留其获授权职责；Dot 转交不创造设计接管、采用或执行权，不新增本地设计主控。技术方法和实际分配由执行主控在任务包范围内细化。

账号、工作区、项目附件、Library 类文件库、资料空间与私有仓库分别核对权限。引用、分享链接和聊天可读不证明文件能进入执行环境。跨环境文件沿 [文件交接](../workflows/v1.9/file-account-handoff.md)，只提交必要版本，不复制私人历史。

不保证永久记忆、后台通知、模型选择或同一工具在所有账号可用。保存指针与紧凑交接，不能把“记住了”当存储证据；无法发消息时输出给用户转交，不声称已发送。发布、通知、加载和启动分开，用户暂停照旧。
