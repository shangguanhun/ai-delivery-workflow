# 项目专属入口模板

模板版本：`portable-collaboration-v1`。仅在目标项目的获授权私有位置填写，经过适用审阅与采用后使用。不把填写后的私人内容提交回公共方法库；占位字段不能授予任务权限。

- 项目与实际入口：（必填：项目身份、真实源码及运行入口，核实后填写）
- 公共规则版本：（必填：实际采用的仓库/固定提交或文件清单身份，不只写 main）
- 环境与规则链：（必填：真实环境适配、项目及嵌套规则入口）
- 目标与验收来源：（必填：已批准原文指针、结果范围和非目标）
- 实际责任：（必填：产品责任、工程主控、主要实现者；能合并的职责不强制分会话）
- 授权与停点：（必填：当前动作范围、数据/存档限制、预算、暂停/恢复及发布边界）
- 模型/工具覆盖：（按需：部署者明确选择和适用范围；未知标未知，不复制个人默认）
- 当前记录：（必填：已有记录位置，动态状态、加载回执和证据留在那里）
- 项目必要例外：（仅按需：覆盖哪项通用默认、来源与范围，不降低高层权限/安全要求）

跨账号文件仍按公共文件交接流程核接收权限，不在这里放凭证。公共库升级不能覆盖旧失败、暂停、已冻结输入或现有专属门槛。
