# 阶段 2：连贯执行、修复与停止空转

规则版本：`portable-collaboration-v1`。写入、派发、修复前读取；须有规划或足够的现有交接。检查另读阶段 3，规则候选另读阶段 5。承接 [公共入口](../../AGENTS.md) 和 [项目工作流](../../workflows/v1.9/project-execution.md)。

## 最小连贯写入批次

写前核 Git 状态、实际目标、责任范围及已有字节；非 Git 检查精确路径。共享/治理文件替换前比对预期。一个受控批次复用新鲜证据，范围变化、他人写入或漂移不明再核。保留无关工作与暂存区，不广泛重置、清理、覆盖或批量暂存。

主要实现者连贯完成实现、自检、相关回归、整合与修复；每次修复先做能验证该修复主张的最便宜有效作者自检。同因或有界相邻的低、中风险修复按真实影响合批：在同一整合候选上做一次影响面回归，需出包时按目标合批出包，不为每个小修反复冻结、打包、独审或跑整套验收。候选变更按阶段 3 只重查受影响主张，仍有效的证据直接复用。高风险及时定向检查并保留必要独审；约定的最终同版独立 QA 不以合批回归替代。必要独审、交付和跨责任接口才固定相关输入；冻结候选不热改，新结果产生新身份并保留原失败。

作者例行交件直达实际集成者，QA 反例直返主要实现者；主控只接需要决定的依赖、风险、资源与采用，不逐件中转、不重读已核的同一批材料。无直接接件能力时，沿已有授权路径必要转交一次。仅主控会话具备的工具/权限或明确接管动作，可限定执行后交回原作者，不借此把全部实现重新揽回。已有成果复用，不因换库或重排从零开发。

## 路线要落实到实际调用

按阶段 1 的能力选择，在下一次获准调用或安全续接中使用主机支持的模型/思考参数。工具固定、不支持切档或没有回读时如实标明，保留足够胜任的既有路线或在原授权内选其他支持方式；不绕过拒绝。请求与实际回执不符，不能说已经调整。

普通单次路由在已授权预算与权限内可覆盖普通默认，不新增逐次审批；用户固定选择、持久设置、服务等级及费用边界不能擅改。不得为了规则升级中断、重启或热改运行中回合。模型建议不是工具支持证据，某平台的配置文件不必然控制另一服务。

仅在实质变化或不匹配时补原记录，复用已有回执，不增加逐调用报告。没有实际费用证据就标未知，不从调用次数、上下文压缩次数或等待次数直接推算 token/账单。

## 阻碍、拒绝与继续

区分待审批、拒绝、超时/中断、缺输入、工程失败与待接收。先查精确原因，工具错误不叫产品未授权；缺证据标 NOT_RUN/UNKNOWN，不编造成产品失败。普通已授权修复无需重新请示，真实数据/权限/产品边界才提具体问题。

仅阻止依赖已证实核心使用、安全/存档、合同风险或缺必要权限/证据的工作；无关获准工作可以继续。有效产品失败不能降格成工具问题。用户明确暂停及冻结/一次性运行约束优先，不借继续其他工作越过其范围。中断先核任务与产物，原因未知不盲目重放，已确认暂停等明确恢复。

拒绝沿原支持路径处理，不换账号、工具、模型或任务做等价重试。精确新授权也不保证平台批准。不要向用户重复询问已经有效授权的同一步骤，也不要在未有新输入时反复催办。

## 两轮后的有界取舍

两次实质迭代未达到目标，或更早已证明路线不适配时，合并反例、排除原因和剩余预算，决定改前提/方法、换适配能力、后置非阻塞细节或返回真实产品/权限问题。两三轮是期望，不是必成、自动升档或强制停工次数。第三次相同失败机制须有改变的前提；换任务名、作者或模型不清零历史。

不确定方法遵守预定有限试验与替代出口。可逆内部试验使用隔离数据，不能因此改真实存档、共享合同或产品承诺。数值实现保留版本、输入、单位、采样/种子与结果；视觉制作按实际尺寸及连续表现自检，来源和使用许可可追溯。

## 紧凑上下文与等待退避

长上下文或反复交接已造成无进展时，在安全节点复用原记录留下结果、未决问题、确切版本、失败证据和下一步。压缩后先读已有紧凑续接记录与具体文件/证据指针，只补当前决定缺失或冲突的事实；无新输入、版本/风险变化或具体缺口，不重读相同证据或整段历史。

适用规则和冻结输入要求的完整读取、真实反例修复、必要诊断、验收、存档/权限安全及独审仍必须做。紧凑记录不是替代缺失原文的许可，也不是中断有效工作、重置失败或解除暂停的理由。

等待已派发结果优先用已核实可靠的完成通知/唤醒。返回同一游标/状态、无新结果或风险信息时，停止立即重复调用与空回执，按预计进展、截止和风险退避；不硬编码固定时间或次数。通知不可靠或不可用，在现有授权与工具支持内选择合理间隔的有界后续检查，仍无新信息就继续退避。

没有独立授权工作可推进时，在不取消运行中任务、不丢失交付的安全节点结束无效协调回合，不为保持 active 空转。原任务保留接收责任、待收结果与实际可用的返回路径，信息足够不另造回执。先核宿主的结束语义，若结束父回合会取消子任务，使用其支持的安全等待/交回方式，不假定任务会独立存活。

结束协调回合或单条路径阻塞，不等于目标/阶段完成、任务取消或放弃接收；完成须以对应约定验收为准。没有可靠返回方式时说明实际缺口，不承诺后台自动回来。不得未经授权新增监控、定时任务、唤醒服务或第二台账；已有获准机制照其范围运行。用户暂停优先于通知和后续检查。
